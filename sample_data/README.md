# Synthetic sample data

Every fund, identifier, holding, benchmark, and price in this directory is fictional. The files are generated by `scripts/generate_sample_data.py` and may be redistributed under CC0-1.0.

The ten PDFs form a labeled extraction-evaluation surface. CSV prices are deterministic adjusted-price-like paths for exercising calculations; they are not market observations. Use the manifest to pair each factsheet, expected extraction, and price file.
